# Security

Report vulnerabilities using GitHub's private vulnerability reporting for this
repository. Avoid posting reproduction details that expose private media.

SceneHarbor runs on localhost and is intended for a single local operator.
Keep the OS, browser, and FFmpeg up to date. Run it with an ordinary user
account. The service can read the video files that the operator selects and
stores imported copies, previews, and exports in its local workspace.

The current supported release line is 1.x.
